      使用配置文件即可
      
      
Guest 
      登录 + 个人账号信息
      查询积分明细
      积分商城兑换商品   Key
Manager
      修改积分规则
      手动给用户添加积分  Key
      积分商场 增删改查商品  



User
      UID
      name
      password
      gender
      role: Guest/Manger
      registerTime
      level: 1/2/3/4/5  10 
      currentPoint
      

PointsTransaction
      UID
      PTID
      number:  正数表示增加积分  负数表示使用积分
      updateTime: 更新时间
      酒店ID: 外部系统传入
      关联订单ID: 外部系统传入

Product
      PID
      名称
      图片URL
      总需积分 5000
      最低需要积分   2000 + 折合成3000积分的钱
      总库存数量
      目前剩余数量

PointsRule
      PRID
      type:类型 1: 针对用户等级  2:针对特定的时间段 
      threshold: 门槛
      PointsRatio: 积分比率(即多少钱折合成都少的积分)
      description

PaymentMethod
      PMID
      type: 1:纯积分 2: 积分+钱 3: 积分+抵扣券
      description
